# Security Policy

</div>

## Report a Vulnerability

**Do not open a public issue, discussion, or pull request for a security
problem.**

Please report security issues privately using one of the options below:

1. **GitHub Security Advisories** — use the
   [Security tab](https://github.com/leonardosalasd/regolith-water-loop/security)
   and choose *Report a vulnerability*.
2. **Email** — write to **leonardo.salas01@outlook.com**.

### What to include

- Your Python version and OS.
- What an attacker can achieve, and what access they would need to do it.
- Steps to reproduce. Please describe the payload rather than attaching anything harmful.

## Credit

If the report is valid and leads to a fix, I'll credit you in the GitHub Security Advisory

There is no paid bug bounty for this project.
